## Minecraft 26.1 — Chaos Tablist 1.2.0

- Fabric, Forge and NeoForge ports for Minecraft 26.1, requiring Java 25.
- Updated GUI extraction, text opacity, player heads, custom PNG textures, fonts, keyboard and mouse input.
- Adapted payload registration, Forge events, permissions, profiles, world clocks and component serialization.
- Resource format 84.0 and data format 101.1 are covered by the bundled pack metadata.
- Preserves the editor, animated Tab, presets, diagnostics, acknowledged network saves, revision conflicts and private placeholders.
- Build includes 82 regression checks per loader. See VALIDATION.md for in-game checks and their scope.
- Install the matching loader JAR. Fabric requires Fabric API. NeoForge 26.1.0.19-beta is the loader used for validation.
