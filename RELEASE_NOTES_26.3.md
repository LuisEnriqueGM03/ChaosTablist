Chaos Tablist **1.2.0 para Minecraft 26.3**, autor **Luis Enrique Gil Mayser**. Requiere **Java 25**.

- Fabric: Loader 0.19.5 y Fabric API 0.162.0+26.3. Rama `fabric-26.3`.
- Forge: 66.0.10. Rama `forge-26.3`.
- NeoForge: 26.3.0.76. Rama `neoforge-26.3`.

Adaptados teclado y ratón al sistema de entrada de 26.3: atajos de guardar, deshacer y rehacer, selección al arrastrar, Escape y Enter. La carpeta de diseños se abre con la API actual de Minecraft. El paquete cubre recursos 97.1 y datos 121.0.

Comprobados en los tres: 85 regresiones por cargador, Tab y nueve pestañas del editor, clics y selección de texto, Ctrl+A/Z/Y, escritura Unicode, Escape, Enter, PNG recibido por red, cabeza e ítem, guardado confirmado mediante Ctrl+S, recuperación de conflictos, presets y simulación vanilla.

Incluye fuentes y SHA-256; las capturas están en las ramas. Las pruebas de juego usan servidor integrado y el transporte real de cada cargador. No se certifica una partida dedicada con dos clientes independientes. La simulación vanilla no es una sesión con otro cliente vanilla real. Consulta VALIDATION.md.

Instala el JAR correspondiente a tu cargador. Fabric requiere Fabric API. Estas variantes son para **Minecraft 26.3**.
