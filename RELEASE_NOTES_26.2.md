Chaos Tablist **1.2.0 para Minecraft 26.2**, autor **Luis Enrique Gil Mayser**. Requiere **Java 25**.

- Fabric: Loader 0.19.5 y Fabric API 0.161.0+26.2. Rama `fabric-26.2`.
- Forge: 65.1.3. Rama `forge-26.2`.
- NeoForge: 26.2.0.90. Rama `neoforge-26.2`.

Adaptados el gestor de pantallas, el HUD, la consulta de GPU, los marcadores y la API de colores. Icono de NeoForge actualizado al formato vigente. Recursos 88.0 y datos 107.1.

Comprobados en los tres: 85 regresiones por cargador, Tab y nueve pestañas del editor, clics y escritura Unicode, PNG recibido por red, cabeza e ítem, guardado confirmado y recuperación de conflictos, presets y simulación vanilla. Incluye fuentes, capturas en las ramas y SHA-256.

Las pruebas de juego usan servidor integrado y el transporte real de cada cargador. No se certifica una partida dedicada con dos clientes independientes. La simulación vanilla no es una sesión con otro cliente vanilla real. Consulta VALIDATION.md.

Instala el JAR correspondiente a tu cargador. Fabric requiere Fabric API. Estas variantes son para **Minecraft 26.2**.
