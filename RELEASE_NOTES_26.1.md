Chaos Tablist **1.2.0 para Minecraft 26.1**, autor **Luis Enrique Gil Mayser**. Requiere **Java 25**.

- Fabric: Loader 0.19.5 y Fabric API 0.145.1+26.1. Rama `fabric-26.1`.
- Forge: 62.0.9. Rama `forge-26.1`.
- NeoForge: 26.1.0.19-beta. Rama `neoforge-26.1`.

Adaptados Tab, editor, fuentes, transparencia, PNG personalizados, teclado y ratón, red, permisos y reloj del mundo.

Comprobados en los tres: 82 regresiones por cargador, editor y nueve pestañas, clics y escritura Unicode, PNG recibido por red, cabeza e ítem, guardado confirmado y recuperación de conflictos, presets y simulación vanilla. Incluye capturas, fuentes y SHA-256.

Las pruebas de juego usan servidor integrado. No se certifica una partida dedicada con dos clientes independientes. En NeoForge la inicialización --initSettings genera los ajustes y termina con código 1 por no crear un hilo de servidor; véase VALIDATION.md para el alcance completo.

Instala el JAR correspondiente a tu cargador. Fabric requiere Fabric API. Estas variantes son para **26.1**, no para 26.1.1/26.1.2.
